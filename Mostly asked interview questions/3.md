21. What are Decorators?

Answer:
Decorators are functions that modify or extend the behavior of another function without changing its code.

22. What is Recursion?

Answer:
Recursion is a technique where a function calls itself to solve smaller instances of a problem.

23. What is the Difference Between Deep Copy and Shallow Copy?

Answer:

Shallow Copy

Copies references of nested objects.

Deep Copy

Creates completely independent copies of all nested objects.

24. What is Garbage Collection?

Answer:
Garbage collection automatically frees memory occupied by unused objects.

25. How Does Python Manage Memory?

Answer:
Python uses:

Reference counting
Garbage collection
Private memory management through the Python memory manager

26. What is the Global Interpreter Lock (GIL)?

Answer:
The GIL allows only one thread to execute Python bytecode at a time, simplifying memory management but limiting CPU-bound multithreading.

27. What is Multithreading?

Answer:
Multithreading allows multiple threads to run within the same process, useful for I/O-bound tasks.

28. What is Multiprocessing?

Answer:
Multiprocessing creates multiple processes that run independently, useful for CPU-intensive tasks.

29. Difference Between Multithreading and Multiprocessing?

Answer:

Multithreading	Multiprocessing
Uses threads	Uses processes
Shared memory	Separate memory
Best for I/O tasks	Best for CPU tasks

30. What is Object-Oriented Programming (OOP)?

Answer:
OOP is a programming paradigm that organizes code into classes and objects.
