31. What are the Four Pillars of OOP?

Answer:

Encapsulation
Abstraction
Inheritance
Polymorphism

32. What is Encapsulation?

Answer:
Encapsulation bundles data and methods together and restricts direct access to internal details.

33. What is Abstraction?

Answer:
Abstraction hides implementation details and exposes only essential features.

34. What is Inheritance?

Answer:
Inheritance allows a child class to acquire properties and methods from a parent class.

35. What is Polymorphism?

Answer:
Polymorphism allows the same interface to behave differently depending on the object.

36. What is Method Overriding?

Answer:
Method overriding occurs when a child class provides a specific implementation of a method already defined in the parent class.

37. Does Python Support Method Overloading?

Answer:
Python does not support traditional method overloading. Similar behavior can be achieved using default arguments or variable-length arguments.

38. What is a Constructor?

Answer:
A constructor is a special method automatically called when an object is created and is used to initialize object attributes.

39. What is MRO (Method Resolution Order)?

Answer:
MRO defines the order in which Python searches for methods in inheritance hierarchies, especially in multiple inheritance.

40. What is Monkey Patching?

Answer:
Monkey patching is the practice of modifying or extending classes or modules at runtime without changing their original source code.
