1. What is Python?


Python is a high-level, interpreted, object-oriented programming language known for its simple syntax, readability, and extensive library support.

2. What are the advantages of Python?

Answer:

Easy to learn and use
Large standard library
Cross-platform support
Object-oriented
Open source
Supports web development, AI, data science, and automation

3. What are Python's built-in data types?

Answer:

Numeric: int, float, complex
Sequence: list, tuple, string
Set: set, frozenset
Mapping: dictionary
Boolean: bool
Binary: bytes, bytearray

Answer:

List	Tuple

6. What is a Dictionary?

Answer:
A dictionary stores data in key-value pairs and provides fast lookup operations.

7. What is the difference between == and is?

Answer:

== compares values.
is compares memory locations (object identity).

Answer:

Mutable:

List

Set

Immutable:

String

Integer

9. What is Type Casting?

Answer:
Type casting is the process of converting one data type into another, such as converting a string to an integer.

10. What is a Python Module?

Answer:
A module is a Python file containing functions, variables, and classes that can be imported into another program.
