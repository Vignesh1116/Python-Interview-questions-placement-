41. What is a Virtual Environment?

Answer:
A virtual environment is an isolated Python environment that allows separate dependency management for different projects.

42. What is the Difference Between Python 2 and Python 3?

Answer:

Python 3 is the current version.
Better Unicode support.
Improved syntax and features.
Python 2 is no longer maintained.

43. What is the Difference Between append() and extend()?

Answer:

append() adds a single element.
extend() adds multiple elements from another iterable.

44. What is the Difference Between remove(), pop(), and del?

Answer:

remove() removes by value.
pop() removes by index and returns the value.
del deletes elements, slices, or variables.

45. What is the Difference Between sort() and sorted()?

Answer:

sort() modifies the original list.
sorted() returns a new sorted list without modifying the original.

46. What is a Context Manager?

Answer:
A context manager automatically manages resources such as files and database connections, ensuring proper cleanup after use.

47. What is the Purpose of the with Statement?

Answer:
The with statement simplifies resource management and automatically closes resources after use.

48. What are Closures?

Answer:
A closure is a function that remembers variables from its enclosing scope even after that scope has finished execution.

49. What are Comprehensions in Python?

Answer:
Python provides:

List Comprehension
Dictionary Comprehension
Set Comprehension

These provide concise ways to create collections.

50. What Happens When a Python Program Runs?

Answer:

Source code is read.
Compiled into bytecode.
Bytecode is executed by the Python Virtual Machine (PVM).
Output is generated.
